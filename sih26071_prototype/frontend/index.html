How this prototype runs

Live IMD radar/INSAT/NWP access requires ministry-level data-sharing agreements unavailable to a student team. This build replays a synthetic-but-physically-modelled heavy rainfall event through the real fusion + ML + inundation pipeline, entirely offline — so the demo cannot fail on venue network or API limits. The same pipeline is built to accept live feeds as a drop-in replacement.
